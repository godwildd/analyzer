# analyzer# Expense Analyzer

Консольный скрипт для анализа личных расходов из CSV-файла.

## Запуск

```bash
python analyzer.py
```

## Формат данных

Файл `data/expenses.csv` — таблица с заголовком:

| Поле          | Формат       | Описание                  |
|---------------|--------------|---------------------------|
| `date`        | `YYYY-MM-DD` | Дата расхода              |
| `category`    | строка       | Категория (еда, транспорт) |
| `amount`      | float        | Сумма в рублях             |
| `description` | строка       | Краткое описание           |

## Что выводит

- Общая сумма расходов
- Средний расход в день
- Расходы по категориям с процентами (по убыванию)
- Самая крупная трата

## Требования

Python 3.8+. Сторонние библиотеки не нужны.
